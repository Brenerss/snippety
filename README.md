# Snippety ✂️

A lightweight and efficient tool to store, organize, and retrieve reusable code snippets. 

## 🚀 Overview

**Snippety** is designed to help developers boost their productivity by providing a centralized place to keep their most used code blocks. No more digging through old projects to find that one useful function!

## ✨ Features

*   **Create & Store:** Easily save code snippets with titles and descriptions.
*   **Language Tagging:** Categorize snippets by programming language.
*   **Quick Search:** Find the exact snippet you need in seconds.
*   **Simple UI/API:** Clean interface for managing your collection.

## 🛠 Technologies

*   **Backend:** Go
*   **Database:** PostgreSQL

## ⚙️ Prerequisites

Before you begin, ensure you have the necessary runtime environments installed for this project (e.g., Node.js, Go, or PHP).

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Brenerss/snippety.git
   ```
2. Navigate to the project directory:
   ```bash
   cd snippety
   ```
3. Install dependencies:
   ```bash
   # Use the appropriate command for your stack:
   # npm install
   # go mod tidy
   # composer install
   ```

## 🏃‍♂️ Running the Application

To start the development server, run:
```bash
go run main.go
```
